# Pixel Documents Studio

This repository contains a modern document and design workspace inspired by a polished studio-style tool. It is built as a static web app so it can be published directly on GitHub Pages.

## Features

- Modern dashboard layout
- Editable document canvas
- Text formatting controls
- Theme color selection
- Page size presets
- Add text, shapes, or uploaded images
- Auto-save to localStorage
- Download project as JSON
- Print-ready layout
- Ready for GitHub Pages deployment

## Run locally

Open `index.html` in a browser, or serve the folder with a simple local server:

```bash
python3 -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Deploy to GitHub Pages

1. Push this repository to GitHub.
2. In the repository settings, open Pages.
3. Select the `main` branch and root folder (`/`).
4. Save.
5. The site will be published at:

```text
https://<your-username>.github.io/pixel-documents-studio/
```
